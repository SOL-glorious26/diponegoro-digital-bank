# Diponegoro Digital Bank - Kotlin Android

Prototype aplikasi bank digital berdasarkan UML yang diberikan:
- Login
- Dashboard
- Transfer antarbank
- Validasi rekening, nominal, saldo, dan PIN
- Riwayat transaksi
- Filter/cari transaksi
- Bukti transfer
- Dashboard pemasukan/pengeluaran

Catatan: ini adalah simulator/prototype akademik, bukan aplikasi perbankan nyata.

Cara memakai:
1. Buat project Android Studio dengan template Empty Activity (Jetpack Compose).
2. Gunakan package `com.example.diponegorodigitalbank`.
3. Salin folder `app/src/main/java/...` dari paket ini ke project.
4. Pastikan Compose Material 3 aktif.
5. Jalankan aplikasi.
